WarOfTheWorlds 실행 방법

1. ZIP 압축을 전부 풉니다. ZIP 내부에서 바로 실행하지 마세요.
2. BUILD-AND-PLAY.cmd를 더블클릭합니다.
3. 첫 실행은 Unity가 게임을 빌드하므로 몇 분 걸릴 수 있습니다.
4. 빌드에 성공하면 Windows 게임 창이 자동으로 열립니다.
5. 이후에는 Builds/Windows/WarOfTheWorlds.exe를 직접 실행하면 됩니다.

필요 조건: Windows, Unity Hub에 설치된 Unity 6000.5.0f1과 Windows Build Support.
이 프로젝트가 Unity에 열려 있다면 먼저 해당 프로젝트만 닫고 실행하세요.
다른 곳에 Unity를 설치했다면 Tools/Build-Game.ps1의 -UnityPath 옵션으로 경로를 지정할 수 있습니다.

학교 규정에 따라 AI는 Unity 에디터/빌드를 실행하지 않았습니다.
이 묶음은 완성된 exe가 아니라, 사용자가 직접 빌드하고 실행하는 프로젝트입니다.
기존 팀 씬 두 개를 그대로 빌드하며 UI/씬을 다시 생성하는 도구는 호출하지 않습니다.
일반 Release 빌드이므로 개발 치트는 작동하지 않습니다.

조작: WASD/방향키 이동, B/V/R/T 스킬, P 보유량, Esc 일시정지.
오프닝: Space/Enter/Esc 또는 건너뛰기 버튼.

실패하면 Builds/windows-build.log를 확인하세요.
Unity 라이선스 로그인이 필요한 경우 Unity Hub에서 직접 로그인/인증해야 합니다.
상세 기능과 남은 검증: FINAL-GAMEPLAY.md.
게임을 다른 PC로 옮길 때는 Builds/Windows 폴더 전체를 함께 복사하세요.
